# 📦 물품관리 통합 앱

물품대장과 재물조사표를 비교해 **일치·불일치 목록, 품명별 수량 합계, 검토용 조정안**을 확인하는 웹 앱입니다.

## 바로 실행하기

**[👉 물품관리 앱 열기](https://kookiki80-debug.github.io/inventory-reconciliation/)**

별도 설치나 회원가입 없이 브라우저에서 사용할 수 있습니다. 오프라인에서 사용하려면 `index.html`을 다운로드해 브라우저로 여세요.

## 사용 방법

1. **물품대장**과 **재물조사표**를 CSV 파일로 준비합니다.
2. 각각의 파일 선택 영역에서 CSV를 선택합니다.
3. 파일의 인코딩을 선택합니다. 기본값은 **UTF-8**이며, 한글이 깨지거나 읽기 오류가 나면 **CP949 / EUC-KR**을 확인하세요.
4. **비교 및 취합** 버튼을 누릅니다.
5. 결과를 검토한 뒤 필요한 목록을 **CSV로 다운로드**합니다.

처음 사용한다면 앱 안에 포함된 **200개 테스트 샘플** 다운로드 링크로 먼저 확인해 보세요.

## CSV 형식

두 파일 모두 다음 제목 행이 필요합니다. 열 순서는 달라도 됩니다.

```csv
관리번호,품명,수량,보관장소
000001,모니터,2,회의실
000002,의자,5,사무실
```

- 지원 파일: **CSV만 가능** (`.xlsx`는 CSV로 변환해야 합니다.)
- 파일 크기: **각 20MB 이하**
- 수량: **0 이상의 숫자**
- 관리번호: 각 파일 안에서 중복되지 않아야 합니다.
- 관리번호에 앞자리 `0`이 있다면 CSV 저장 과정에서 없어지지 않도록 주의하세요.

## 확인할 수 있는 결과

| 결과 | 설명 |
| --- | --- |
| 일치 목록 | 관리번호·품명·수량·보관장소가 같은 물품 |
| 불일치 목록 | 한쪽에만 있는 물품이나 품명·수량·보관장소 차이 |
| 검토 필요 항목 | 관리번호 중복, 잘못된 수량, 열 개수 오류 등 |
| 품명별 취합 | 동일한 품명의 수량을 각 자료에서 따로 합산 |
| 현장 조정 안내 | 수량·위치 차이에 대해 담당자가 검토할 안내 |
| 대장 기준 정리안 | 조사 원본 정보와 검토 상태를 포함한 별도 정리안 |

품명은 앞뒤 공백을 제거한 뒤 **정확히 같은 이름끼리** 묶습니다. 비슷한 이름을 자동으로 같은 물품으로 판단하지 않으며, 물품대장과 재물조사표의 수량을 서로 더하지 않습니다.

입력 오류가 있으면 부분 비교 결과만 제공하고, 오류 수정 전까지 취합과 CSV 내보내기를 보류합니다.

## 데이터와 업무 사용 시 주의사항

- 선택한 CSV는 **브라우저 내부에서 처리**하며, 앱 코드에는 서버로 전송하는 기능이 없습니다.
- 이 저장소에는 앱 코드와 내장 테스트 샘플만 포함됩니다. 원본 폴더의 업무 문서나 별도 실제 CSV는 업로드하지 않습니다.
- **공개 저장소이므로 HTML에 내장된 테스트 샘플도 공개됩니다.**
- 비교 과정에서 사용자가 선택한 원본 CSV 파일을 수정하지 않습니다.
- 다운로드한 조정 안내와 정리안은 **검토용 제안**이며, 조치 완료나 공식 대장 정정을 의미하지 않습니다.
- 실제 자료 사용은 소속 기관의 승인을 받고, 정정·이동·불용 판단은 담당자가 확인하세요.
- 품명별 합계는 물품의 수량 단위가 같은지 확인한 뒤 사용하세요.

## 파일 구성

```text
inventory-reconciliation/
├── index.html       # 원본 물품관리_통합앱.html을 복사한 실행 파일
├── README.md        # 사용 방법과 주의사항
├── .gitattributes   # HTML 원본 바이트를 보존하는 설정
├── .gitignore       # 실제 업무 자료와 로컬 설정의 실수 업로드 방지
└── .nojekyll        # GitHub Pages 정적 파일 배포 설정
```

화면·스타일·비교 기능·테스트 샘플이 HTML 한 파일에 들어 있습니다. 별도 서버, 외부 라이브러리, API 키가 필요하지 않습니다.

## 앱 수정 후 업데이트

이 저장소 폴더에서 `index.html`을 수정한 뒤 실행하세요.

```sh
git status
git add index.html README.md
git commit -m "Update inventory app"
git push
```

- **commit**: 변경 내용을 내 컴퓨터에 기록합니다.
- **push**: 기록을 GitHub로 보냅니다.
- `main` 브랜치에 푸시하면 GitHub Pages가 자동으로 다시 배포됩니다.
- [Actions 페이지](https://github.com/kookiki80-debug/inventory-reconciliation/actions)에서 배포 진행 상황을 확인할 수 있습니다.

> **코드 수정 시 주의:** HTML에는 스크립트와 스타일의 SHA-256 해시를 사용하는 콘텐츠 보안 정책(CSP)이 있습니다. `<script>`나 `<style>` 내용을 수정하면 해당 해시도 다시 계산해 업데이트해야 합니다. 그렇지 않으면 브라우저가 실행을 차단할 수 있습니다.
